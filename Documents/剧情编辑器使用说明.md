# 剧情编辑器使用说明（C13–C18）

> 适用范围：`Game/Story Authoring Window`（IMGUI EditorWindow）。
> 当前阶段：C18 剧情编辑器功能已完成基础版本，**分支/汇合（Choice/Goto）依赖节点 Type 下拉切换**，尚无独立添加按钮、节点排序、Undo/Redo 与脏标记。

---

## 1. 打开编辑器

菜单栏：`Game → Story Authoring Window`

窗口提供四个操作按钮：

| 按钮 | 功能 |
|---|---|
| `New` | 新建剧情：生成 `start`(Dialogue) → `end`(End) 模板 |
| `Open` | 打开 `.story.authoring.json` 文件 |
| `Save` | 保存为 `.story.authoring.json`（临时文件 + 原子替换） |
| `Compile` | 校验并编译为 Runtime JSON 信封 |

---

## 2. 剧情数据模型

剧情文件为 `.story.authoring.json`，顶层结构：

```json
{
  "StoryId": "official.story.c06_branch",
  "StartNodeId": "start",
  "Nodes": []
}
```

### 节点类型（`StoryNodeType`）

| 类型 | 必填字段 | 作用 |
|---|---|---|
| `Dialogue` | `TextKey`、`NextNodeId` | 播放一段对白后进入下一节点 |
| `Choice` | `Choices`（≥1 项） | 等待玩家选择后进入对应分支 |
| `Goto` | `NextNodeId` | 无展示跳转到目标节点 |
| `End` | — | 剧情序列结束 |
| `ShowCharacter` | `SpeakerCharacterId`、`NextNodeId` | 显示/刷新角色立绘 |
| `ShowCg` | `AssetId`、`NextNodeId` | 显示全屏 CG |
| `SetBackground` | `BackgroundId`、`NextNodeId` | 切换背景 |
| `HideCharacter` | `SpeakerCharacterId`、`NextNodeId` | 隐藏角色立绘 |
| `MoveCharacter` | `SpeakerCharacterId`、`CharacterPosition`、`NextNodeId` | 移动立绘到左/中/右 |
| `PlayAudio` | `AudioId`、`AudioKind`、`NextNodeId` | 播放音乐/音效 |
| `ScreenEffect` | `EffectType`、`NextNodeId` | 白闪/红闪/黑屏/模糊等 |
| `Wait` | `WaitSeconds`、`NextNodeId` | 可跳过的等待 |

### 节点通用字段

- **Node ID**：节点在剧情内的唯一稳定标识，不得重复。
- **Speaker Key**：说话人本地化键（Dialogue/ShowCharacter/HideCharacter/MoveCharacter）。
- **Speaker Character**：说话角色稳定标识（`official.character.*`）。
- **Appearance Override**：显式形象覆盖；为空时使用角色当前默认形象。
- **Next Node**：下一节点标识；`End` 节点可为空。

## 3. 编辑流程

### 3.1 新建剧情

点击 `New`：

```json
{
  "StoryId": "story.new",
  "StartNodeId": "start",
  "Nodes": [
    { "NodeId": "start", "Type": "Dialogue", "TextKey": "story.new.start", "NextNodeId": "end" },
    { "NodeId": "end", "Type": "End" }
  ]
}
```

修改 `Story ID`、`Start Node` 后继续编辑节点。

### 3.2 添加节点

点击 `Add Dialogue Node` / `Add Show Character Node` / `Add Show CG Node` / `Add Set Background Node` / `Add Hide Character Node` / `Add Move Character Node` / `Add Play Audio Node` / `Add Screen Effect Node` / `Add Wait Node`。

新节点默认 `NodeId = "node_N"`、`NextNodeId = "end"`，需手动改为实际目标。

> **分支限制**：`Choice` 与 `Goto` 节点没有独立添加按钮。如需创建，请：
> 1. 添加任意节点（如 Dialogue），
> 2. 在 Inspector 中把 `Type` 下拉改为 `Choice` 或 `Goto`，
> 3. 填写 `Choices` 列表（Choice 节点）或 `NextNodeId`（Goto 节点）。
>
> C18 发布前已计划补齐（排序、Undo/Redo），未包含在此版本。

### 3.3 编辑分支（Choice）

`Choice` 节点可点击 `Add Choice` 增加选项，每项包含：

- **Choice ID**：选项稳定标识，不得重复。
- **Choice Text**：选项本地化键。
- **Choice Target**：选择后跳转的节点标识。

### 3.4 删除节点

点击节点下方的 `Remove Node` 按钮。删除后需手动检查被引用的 `NextNodeId`/`Choice Target`，Compile 时会校验并报错。

### 3.5 预览节点

点击 `Preview Node` 查看该节点字段的轻量摘要（非演出预览；正式演出预览在 C17 后半计划中）。

## 4. 校验与编译

### 4.1 编译校验项（`StoryDefinitionValidator`）

点击 `Compile` 时执行完整校验，失败弹窗显示错误，**不覆盖上次有效输出**：

| 类别 | 校验规则 |
|---|---|
| 基础 | StoryId / StartNodeId / Nodes 非空，NodeId 唯一 |
| 对白 | Dialogue 必须有 `TextKey` |
| 分支 | Choice 至少 1 项，ChoiceId 唯一，目标非空 |
| 引用 | `NextNodeId`/`Choice Target` 必须指向存在的节点；StartNodeId 存在 |
| 角色 | `SpeakerCharacterId` 存在（可选传入角色集）；`AppearanceOverride` 属于角色 |
| 演出 | ShowCharacter 必须有角色；ShowCg/SetBackground/PlayAudio 必须有资源 ID；ScreenEffect 非 None；Wait > 0 |
| 资源 | 资源 ID 必须登记在 `ContentAssetRegistry`（含 GameRoot 引用或全量扫描） |
| 本地化 | Dialogue/Choice/Speaker 的本地化键必须存在于 UI String Table（表缺失时不阻断） |

### 4.2 编译输出

`Compile` 成功后将信封写入：

```
Assets/Game/Resources/StoryRuntime/<StoryId>.story.runtime.json
```

信封格式（`StoryRuntimeEnvelope`）：

```json
{
  "FormatVersion": 1,
  "SourceHash": "<sha256前16位>",
  "Story": { ... }
}
```

- `FormatVersion`：当前运行时只接受 1。
- `SourceHash`：节点按 NodeId 稳定排序后序列化的 SHA-256 前 16 位（内容变更时变化）。
- 写入采用 `.tmp` → 替换的原子流程，失败不破坏上次有效文件。

> 运行时读取：`GeneratedStoryLoader.LoadAll()` 从 `Resources/StoryRuntime` 读取
> （`GameRoot` 启动时注入 `GameRuntimeServices.SetGeneratedStories`），
> 编译产物可直接被游戏运行时播放，无需手动拷贝。

---

## 5. 运行时播放链路

编译后剧情进入游戏的路径：

```
StoryAuthoringWindow.Compile
  → Assets/Game/Resources/StoryRuntime/*.story.runtime.json
  → GeneratedStoryLoader.LoadAll()（GameRoot 启动时注入）
  → StoryScenePresenter 查找 GeneratedStories（优先）
  → StoryRunner 按节点执行
  → StoryDialoguePanel 渲染（背景/立绘/对白/选项/效果）
```

若 Generated 目录无对应剧情，`StoryScenePresenter` 回退
`OfficialTestMapCatalog` 中的测试剧情 `official.story.c06_branch`。

---

## 6. 测试模板（推荐起点）

新建剧情后按以下结构快速搭建线性演示（`test_01` → `test_02` → `end`）：

```json
{
  "StoryId": "official.story.demo_showcase",
  "StartNodeId": "test_01",
  "Nodes": [
    {
      "NodeId": "test_01",
      "Type": "Dialogue",
      "TextKey": "demo.story.line_01",
      "NextNodeId": "test_02"
    },
    {
      "NodeId": "test_02",
      "Type": "Dialogue",
      "TextKey": "demo.story.line_02",
      "NextNodeId": "end"
    },
    { "NodeId": "end", "Type": "End" }
  ]
}
```

> 注意：`TextKey` 必须先存在于 `UI.csv` 并执行 `Boom Jam/Localization/Import UI CSV`
> 生成 String Table，否则 Compile 时资源/本地化校验会提示缺失（本地化表缺失时
> Compile 不阻断，但运行时显示键名）。
