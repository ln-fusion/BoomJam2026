# C20 程序 B：回溯与传送验证

本轮交付两个可运行物理验证，不替代正式关卡世界、车辆控制器、部署界面或结算流程。矩形 `Car` 是小车的运动替身，`Box` 是第二个可独立受影响的对象。

## 如何运行

1. 使用 Unity 2022.3.62f3，打开 `Assets/Scenes/90_C20_TemporalSpike.unity`，直接 Play，无需 Bootstrap。
2. 默认回溯模式：上方青色 Car、下方黄色 Box 向右移动，进入紫色框后瞬间回到约两秒前的位置，速度保持，框消失。继续运行不会再次回溯。
3. 点击 `Restart Rewind` 可重新验证。勾选 `Block Car history after it passes` 后重新开始：小车经过后，红色障碍出现在过去位置；回溯将选择较近的安全历史，Box 不受影响。
4. 点击 `Restart Teleport`：紫色为单向入口，绿色细线为出口；对象瞬移到出口后继续向右，随后与末端灰色墙正常碰撞。出口本身没有反向入口能力。
5. `Pause`／`Resume` 仅控制验证场景。面板显示 Tick、共享回溯秒数、快照数组有效载荷和最近触发结果。

场景默认不加入正式 Build Settings。重启按钮重建并卸载旧本地物理场景，不触碰玩家存档。

## 配置与代码入口

| 修改目标 | 入口 |
|---|---|
| 全部框的默认回溯时间 | 场景根对象 `C20TemporalDemo.Rewind Seconds`，默认 2 秒；修改后重新运行或重启验证 |
| 回溯状态字段 | 构造 `TemporalAbilityWorld` 时传 `RewindStateFields`；位置必选，默认恢复全部运动字段 |
| 新增可回溯／传送目标 | 独立根对象挂 `Rigidbody2D`、单个 `BoxCollider2D`、`TemporalBody2D`，配置稳定 ID，并注册到所属世界 |
| 场景装置或能力框入口 | 挂 `TemporalTrigger2D`，选择 Rewind 或 Portal；Portal 指向同一本地场景的出口 Transform，并注册到世界 |
| 单对象历史 | `RewindHistory` 的固定容量数组，按 Tick 升序查询 |
| 能力端口草案 | `TemporalAbilityContracts.cs` 中 `IRewindableState`、`ITeleportable` |

`TemporalBody2D` 当前共用两个端口，但可分别关闭回溯或传送资格。框的外观不参与传送判断。移动操作发生在统一物理后阶段；传送后必须离开入口区域才能重新触发，不能依赖物理回调先后决定谁获胜。

## 内存预算

快照包含 `long Tick`、两个 `Vector2`、两个 `float`，在目标环境验证为 32 字节。

| 配置 | 每对象槽位 | 每对象快照字节 | 64 对象快照字节 |
|---|---:|---:|---:|
| 默认 2 秒，60 Hz | 121 | 3,872 | 247,808（约 242 KiB） |
| 配置上限 10 秒，60 Hz | 601 | 19,232 | 1,230,848（约 1.17 MiB） |

槽位包含起始快照，满后覆盖最早记录；历史数据不随运行总时长增加。最多注册 64 个目标和 64 个入口，超过即拒绝。表中只统计快照数组有效载荷，另有固定规模托管容器、碰撞查询缓冲和 Unity 原生物理对象，不把表中数值冒充整个场景内存。

## 验证结果与限制

- 新增 3 项 EditMode 测试：有界历史与内存布局、阻挡后向现在查找、空历史及重复 Tick。
- 新增 7 项真实本地物理测试：两秒回溯、最早记录与首对象选择、当前世界障碍回退、失败仍消耗、传送状态保持与重复使用、出口重叠防循环、资格过滤与出口后的实体碰撞。
- 新增 1 项场景启动测试：实际 Scene 无需 Bootstrap 即可运行并推进两个对象。
- 本轮全量 PlayMode：13 通过、0 失败。全量 EditMode：137 通过、7 失败；失败来自未修改的剧情目录、剧情文本校验和历史记录测试，不计作 C20 全部回归通过。
- EditMode 待修复项：`GeneratedStoriesAndLevelReferencesUseOneCatalog` 的关前剧情引用缺失；`TryValidate_MissingLocalizationKey_Fails` 与当前校验行为不一致；`StoryHistoryPanelTests` 四项及 `StorySkipHistoryTests.Skip_RecordsVisitedNodesIntoHistory` 的文本预期与当前表现不一致。

当前只支持独立动态矩形碰撞体，不支持关节／车厢联动、复合碰撞体、回溯尺寸／生命值或整世界回滚。触发依赖物理 Enter 事件，高速一步跨越整个触发区的扫掠检测留给 C39。出口畅通是内容约束，本轮没有扩展出口寻位规则。位置查询容量溢出时保守视为阻挡；先完成独立对象的架构验证，再扩展正式能力与车辆适配。
